# Saray Kafe POS Panel

İlk MVP:
- Masa / Paket / Gel Al seçimi
- Ürün kartları
- Sipariş toplamı
- Siparişi kaydetme
- Ödeme alma
- Supabase products, orders, order_items tablolarına kayıt

## Kurulum
1. Bu projeyi GitHub'a yükle.
2. Vercel'de import et.
3. Environment Variables kısmına şunları ekle:
   - VITE_SUPABASE_URL
   - VITE_SUPABASE_ANON_KEY

Supabase değerlerini:
Project Settings > API kısmından alacaksın.
